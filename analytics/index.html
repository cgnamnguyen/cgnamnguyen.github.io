Lấy file CSV ở đâu?

AdMob: AdMob → Reports → chọn report theo Date + App → Download CSV. Cột cần có: Date, Estimated earnings, Impressions, Ad requests, Clicks.
Play Console: Play Console → Statistics → chọn app → chọn metric (Install events / Uninstall events) → Export report (raw data).
LevelPlay / Unity Ads: dashboard của từng mạng cũng có nút export CSV — cột tên khác nhau nhưng chỉ cần có cột ngày + số là trang này đọc được, vì nó tự nhận diện tên cột.
Deploy free: kéo file index.html này thả vào app.netlify.com/drop là có link ten-cua-may.netlify.app — nhưng nhớ cảnh báo ở trên: đừng up dữ liệu thật lên link công khai.
